# Heirloom frontend

React and Vite interface for **Heirloom: digital legacy, preservation & access system**.

Author: Vigya Upadhyay. Partners: Kunal choudhary and priyansh.

Use Node.js 24 and npm 11. Run `npm ci`, then `npm run dev`. The Django API must be running on port 8000 for authentication and data access. For deployment, configure `VITE_API_URL` as described in the [project README](../README.md).

Checks: `npm run lint` and `npm run build`.
